# MarketingBot

Telegram-бот на Python для продвижения обучающего курса по созданию бизнеса с нуля и выходу на первые продажи в течение 30 дней.

## Описание

Бот работает в режиме long polling и реализует простой вороночный сценарий:

1. Пользователь отправляет команду `/start`.
2. Бот приветствует его, показывает изображение `media/business1.jpeg` и краткое описание курса.
3. Пользователь нажимает инлайн-кнопку «💰 Записаться на курс».
4. Бот обрабатывает callback `enroll_business`, отправляет `media/business2.png` и ссылку на страницу регистрации.

## Структура проекта

```
MarketingBot/
├── main.py                 # Точка входа: инициализация бота, диспетчера и хендлеров
├── keyboards.py           # Фабрика инлайн-клавиатур
├── media/
│   ├── business1.jpeg     # Изображение для приветствия
│   └── business2.png      # Изображение для шага с регистрацией
├── .env                   # Токен Telegram-бота (в git не коммитится)
└── .gitignore
```

## Технологии

- Python 3.x, asyncio
- [aiogram 3](https://docs.aiogram.dev/) — фреймворк для Telegram-ботов
- Telegram Bot API (long polling)

## Установка и запуск

1. Клонировать репозиторий и перейти в директорию проекта.
2. Создать виртуальное окружение и установить зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install aiogram python-dotenv
```

3. Создать файл `.env` с токеном бота:

```
TOKEN=123456:ABC-DEF...
```

4. Запустить бота:

```bash
python main.py
```

## Хендлеры

| Хендлер | Триггер | Действие |
| --- | --- | --- |
| `cmd_start` | Команда `/start` | Приветствие с фото и кнопкой записи |
| `enroll_business` | Callback `enroll_business` | Отправка изображения и ссылки на регистрацию |

## Токен бота

Бот работает с тестовым аккаунтом **@BebossMentorBot**. Токен хранится в `.env` и не попадает в репозиторий.
